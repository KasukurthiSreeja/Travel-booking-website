# 🌍 Travel Website

## 📌 Description
A responsive travel website developed using **HTML, CSS, and JavaScript** that allows users to explore destinations, view travel information, and manage booking activities through an interactive user interface.

## ✨ Features

- 🏝️ Explore travel destinations
- 🔐 Login and signup pages
- 🧳 Booking interface
- 📊 User dashboard
- 🖼️ Image gallery
- 📞 Contact form
- 📱 Responsive design for different devices
- ⚡ Interactive UI using JavaScript

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
